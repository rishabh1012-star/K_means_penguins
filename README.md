# Penguin Species Clustering Using K-Means

## Overview

This project applies **K-Means Clustering**, an unsupervised machine
learning algorithm, to penguin data.

The goal is to group penguins based on their physical characteristics
without using the species label during clustering. **PCA (Principal
Component Analysis)** is then used to reduce the feature space to two
dimensions so that the resulting clusters can be visualized.

## Dataset

The project uses a penguin dataset containing measurements of penguins.

The features used in the clustering workflow are:

-   `culmen_length_mm`
-   `culmen_depth_mm`
-   `flipper_length_mm`
-   `body_mass_g`
-   `sex`

The `sex` column is converted from categorical values to numerical
values:

-   `MALE` → `0`
-   `FEMALE` → `1`

## Workflow

The notebook follows these main steps:

1.  Load the penguin dataset using Pandas.
2.  Remove rows containing missing values.
3.  Remove selected rows during data cleaning.
4.  Convert the `sex` column into numerical values.
5.  Apply `RobustScaler` to:
    -   `body_mass_g`
    -   `flipper_length_mm`
6.  Visualize the feature distributions using a box plot.
7.  Use the **Within-Cluster Sum of Squares (WCSS)** / Elbow Method to
    examine different values of `K`.
8.  Apply K-Means clustering with `K = 5`.
9.  Store the cluster assignment of each penguin in a new `cluster`
    column.
10. Apply PCA with `n_components=2`.
11. Visualize the resulting clusters using a Seaborn scatter plot.

## Machine Learning Approach

### K-Means Clustering

K-Means is an unsupervised learning algorithm that divides observations
into `K` clusters based on their feature similarity.

In this implementation:

``` python
km = KMeans(n_clusters=5)
data['cluster'] = km.fit_predict(data)
```

A new `cluster` column is created to identify the cluster assigned to
each penguin.

### Choosing the Number of Clusters

The notebook calculates WCSS for values of `K` from 1 to 20:

``` python
wcss = []

for i in range(1, 21):
    km = KMeans(n_clusters=i)
    y_pred = km.fit_predict(data)
    wcss.append(km.inertia_)
```

The WCSS values are then plotted to inspect the Elbow Method and help
assess the choice of `K`.

### PCA Visualization

Because the dataset contains five features, it cannot be directly
visualized in a normal 2D scatter plot.

PCA is used to transform the feature space into two principal
components:

``` python
pca = PCA(n_components=2)
x_scaled = pca.fit_transform(X)
```

The resulting two-dimensional representation is plotted with the K-Means
cluster labels:

``` python
sns.scatterplot(
    x=x_scaled[:, 0],
    y=x_scaled[:, 1],
    hue=data['cluster']
)
```

## Visualization

The final visualization shows:

-   **X-axis:** Principal Component 1
-   **Y-axis:** Principal Component 2
-   **Color:** K-Means cluster assignment

Each point represents one penguin, while the color indicates the cluster
assigned by K-Means.
